The 4-Stage Pipeline

Stage 01
🧠

Parsing Phase

A Hybrid Router processes natural language input. Simple problems use fast Regex rules. Advanced queries — rotational springs, thermal loads, stepped stiffness — are dispatched to local Ollama (Llama-3) via LangChain. Pydantic enforces strict schema validation at the boundary.

LangChain Ollama Llama-3 Pydantic Regex Router
Stage 02
✅

Validation Phase

The raw JSON payload is assembled into a typed domain model. Geometric checks enforce 0 ≤ x ≤ L for all loads and supports. Mechanical validation verifies positive stiffness (EI > 0). Material properties are auto-filled via standards database lookup.

Pydantic Models Material DB ChromaDB RAG IS 808 / AISC
Stage 03
⚙️

Solving Phase

A Solver Router dispatches statically determinate beams to analytical closed-form scripts. Indeterminate beams (fixed-fixed, continuous, variable EI) are solved by a 1D Euler-Bernoulli FEM Engine: assembles global stiffness [K], applies boundary restraints, and solves [K]{u} = {F} via SciPy.

NumPy FEM SciPy Linalg Analytical Solver Self-Weight
Stage 04
📊

Reporting Phase

FastAPI exposes async REST endpoints and streams tokens via Server-Sent Events. The browser consumes the response via async fetch() and renders real-time interactive SFD, BMD, deflection, and Margin of Safety diagrams. Standalone HTML and PDF reports are auto-generated.

FastAPI Async Fetch SSE Chart.js / SVG HTML / PDF

What makes it special

Natural Language Input

Describe your beam in plain English — no rigid syntax. The Hybrid Router extracts spans, loads, and boundaries intelligently.

⚡

Adaptive FEM Solver

Auto-selects analytical or FEM solvers. 1D Euler-Bernoulli elements assembled with NumPy; solved with SciPy in milliseconds.

📐

Engineering Accuracy

Cantilevers, simply-supported, fixed-fixed, continuous beams — all solved with rigorous structural mechanics and verified margins.

📊

Interactive Diagrams

Real-time SFD, BMD, axial force, deflection, and bending stress diagrams rendered via Chart.js and Canvas with sign conventions.

🔒

Pydantic Validation

Every boundary condition and material parameter is strictly validated. Corrupt or impossible inputs are rejected before reaching the solver.

📄

Auto Report Generator

Generates professional standalone HTML and PDF engineering calculation reports including interpolation tables and Margin of Safety with self-weight.
